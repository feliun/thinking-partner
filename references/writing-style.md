# Writing Style

> How I write and how my voice should sound.
> **Mandatory** for `/ghost` — the command cannot match your voice without this file.
> **Edit this file** with your own writing DNA.

---

## 1. Core Writing Philosophy

I write to:

- **Think clearly**
- **Make others think**
- **Leave readers with a sharper mental model**

I do **not** write to:

- Motivate
- Entertain for its own sake
- Chase engagement

---

## 2. Voice DNA

- **Calm, confident, precise.** No performative enthusiasm.
- **Declarative.** State a position. Explain it. Move on.
- **Slightly contrarian.** Question defaults. Deconstruct slogans into mechanisms.
- **Physical verbs for abstract ideas.** "The strategy collapses" beats "the strategy fails."
- **No hedging.** If I'm uncertain, I say so explicitly, then still commit.

---

## 3. Sentence Patterns

**Short paragraphs.** Two-to-four sentences each, usually. White space is a tool.

**Rhythm matters.** Alternate short and medium sentences. Avoid long sentences unless they earn it.

**Sparingly used devices:**

- **Bold** for the one concept in a section that matters most
- Rhetorical questions — max one per piece
- Lists — when the content is genuinely parallel, not for visual padding

---

## 4. Formatting Rules

- **Always use contractions** (don't, can't, won't) — never the expanded form in flowing prose
- **No em dashes (—).** Use commas, periods, or parenthetical brackets instead
- Headers follow a clear hierarchy: H1 for piece title, H2 for sections, H3 sparingly
- Code blocks only for code or structured data
- Tables when comparing, not for decoration

---

## 5. Banned Phrases

Never use:

- "In today's fast-paced world..."
- "Leverage" as a verb (reclaim it as a noun)
- "Game-changer"
- "Synergy"
- "At the end of the day..."
- "It's important to note that..."
- "Moving forward..."
- Any sentence starting with "In conclusion"
- "Delve", "navigate" (as metaphor), "tapestry", "landscape" (as metaphor)

---

## 6. Structural Templates

### For an essay

1. **The claim** — one sentence, stated cleanly up front
2. **The counter-intuition** — why people think otherwise
3. **The mechanism** — what's actually happening
4. **The evidence** — specific examples, data, or vault-grounded references
5. **The implication** — what changes if this is right

### For a response to a question

1. **Direct answer** in the first sentence
2. **Reasoning** in one paragraph
3. **Caveat or edge case** if genuinely necessary, not reflexively

---

## 7. The Test

After drafting, ask:

- Would I cross the street to read this? If no, cut it.
- Is there a clearer way to say this in fewer words? If yes, rewrite.
- Am I telling people what I think, or performing thinking? If performing, cut.
